# Mini WhatsApp

## Necesitas
- Node.js instalado en el ordenador que hará de servidor.

## Arrancar
Abre una terminal en esta carpeta:

    npm install
    npm start

En el ordenador:
    http://localhost:3000

## Desde el móvil
El móvil y el ordenador deben estar en la misma Wi‑Fi.

En Windows, ejecuta:

    ipconfig

Busca "Dirección IPv4". Por ejemplo:
    192.168.1.25

En el móvil abre:
    http://192.168.1.25:3000

## Qué incluye
- Varios usuarios conectados a la vez.
- Mensajes en tiempo real.
- Lista de usuarios conectados.
- Historial de los últimos 1000 mensajes guardado en data/messages.json.
- Diseño adaptable a móvil.
- Nombre guardado en el navegador.

## Importante
Es un proyecto personal/local. Para publicarlo en Internet habría que añadir cuentas,
contraseñas, HTTPS, moderación, base de datos, protección anti-spam y otras medidas.
